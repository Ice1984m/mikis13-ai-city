# Mikis13 AI City

Multi-agent engineering and innovation system.

Leadership:

- Astra — Supreme Judge
- Orion — Chief Coordinator / Right Hand
- Vega — Independent Second Judge

Specialists:

- engineers
- inventors
- creative agents
- researchers
- failure analysts
- security guardians
- business analysts

Flow:

Ideas / Evolution / GitHub
→ Orion
→ specialists
→ debate max 2 rounds
→ jury
→ Vega challenge
→ Astra decision
→ blueprint
→ experiment
→ tests/security/health
→ learning memory

Run:

    mikis-city

Add a task:

    mikis-city-task "Improve website hosting reliability"

Status:

    mikis-city-status

External paid AI providers are disabled by default.

No blind merge.
No secrets.
No automatic payments.
No crypto trades.
No paid advertising.
