# Mikis13 City Council

City Council V16 beheert maximaal één miljoen virtuele
worker-identiteiten. Dit zijn beschikbare rollen, geen miljoen
gelijktijdige Linux-processen.

## Beslissingsproces

1. Repository inspecteren.
2. Bewijs verzamelen.
3. Forumonderwerp maken.
4. Council laat goedkeuren, weigeren of uitstellen.
5. Maximaal één reparatie uitvoeren.
6. Tests en securitycontrole uitvoeren.
7. Pull request aanbieden.
8. Resultaat en motivatie vastleggen.

## Veiligheidsgrenzen

- Geen directe wijzigingen aan main.
- Geen automatische merge.
- Geen force-push.
- Geen willekeurige AI-shellcode.
- Onbekende resultaten gelden niet als geslaagd.
- Externe communityrepositories blijven read-only.
- Bijdragen aan andere projecten vereisen toestemming.
